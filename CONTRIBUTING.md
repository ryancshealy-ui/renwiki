# Contributing to RenWiki

Guidelines for Ryan and Chelsie to collaborate on RenWiki updates.

## Quick Edit Guide

### Updating Show Data
1. Open `shows-data.json` in GitHub
2. Click the pencil icon (Edit)
3. Add/modify shows using the same format
4. Click "Commit changes" and add a message like "Add May shows" or "Update Häxan dates"

### Updating HTML Content
1. Open any `.html` file in GitHub
2. Click the pencil icon to edit
3. Make changes (search/replace works great for small tweaks)
4. Commit with a descriptive message

### Adding New Features
1. Download all files to your computer
2. Edit locally in a text editor (VS Code, Sublime, etc.)
3. Test by opening the HTML file in Chrome
4. Upload the updated files back to GitHub

## Workflow for Changes

### Small Changes (show dates, vendor info, etc.)
1. Edit directly in GitHub (pencil icon)
2. Commit with a message
3. Done! Deployed automatically

### Bigger Changes (adding features, redesigning)
1. Clone/Download the repository
2. Edit locally and test in Chrome
3. Upload changed files
4. GitHub Pages auto-updates

## Tips

- **Always add a commit message** - Helps track what changed and when
- **Test before committing** - Download and open in Chrome to verify
- **Don't break the JSON** - If editing shows-data.json, make sure the brackets/commas are correct
- **Keep file names the same** - Changing file names breaks links
